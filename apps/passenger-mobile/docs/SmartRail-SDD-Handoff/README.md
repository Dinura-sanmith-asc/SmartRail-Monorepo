# SmartRail SDD handoff package

1. Extract the entire ZIP, keeping the `SmartRail-SDD-Handoff/` directory intact.
2. Open `handoff.md` in a Markdown viewer with local-image support (for example, a desktop Markdown editor preview).
3. Keep `assets/`, `evidence/`, `requirements-inventory.md` and `source-manifest.json` alongside it. All document links are relative; no sandbox paths or network access are needed.
4. Read the architecture-supersession note before using any diagram labels. Images are unchanged originals.

The standalone Markdown download is convenient for text review; download/extract the ZIP for its images and supporting evidence to render. This package is a design handoff, not runnable application code. SHA-256 hashes in `source-manifest.json` identify the exact source copies.
