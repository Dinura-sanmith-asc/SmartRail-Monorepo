## Authentication and authorization
API derives opaque subject only from validated JWT. Current PostgreSQL roles are checked every protected call. Driver assignment list is own-only; Controller may read all by its existing grant. Driver submission checks current role and exact active assignment, including on idempotent replay. Controller review uses existing global `ReviewDriverObservations`. No JWT group grants. Missing/invalid token 401, verified insufficient grant/scope 403, missing journey 404, invalid payload 400, conflicting retry 409, unavailable identity/assignment/journey authority 503. RFC 9457 responses omit internal details.

## Persistence and transactions
One active assignment per driver/journey via partial unique index; restrictive journey/assignment FKs and lifecycle constraints; immutable grant/revoke evidence. Observation stores original assignment, journey, server captured revision, verified driver, UTC report time, request UUID and canonical text. Unique `(DriverSubject, RequestId)` supports retry: after current authorization, same canonical payload returns original; conflicting reuse returns 409. Assignment lifecycle/audit writes atomic. Observation write and expected owner validation must not leave partial records on failure. Schema/constraints plus integration tests verify rollback and concurrent retries.

## Cross-module integration
Implement existing `IDriverJourneyAssignmentEvidence` with current persisted assignments. Assignment response composes `IJourneyReadRepository` snapshot and update history, preserving source operation dates and overnight instants. Implement existing `IDriverObservationVerifier` using current review grant, stored observation, same target journey, original still-active assignment, and existence of captured journey revision. No arbitrary age cutoff; stale/revoked is incompatible, owner failure unavailable. Feature 003 persists only the approved optional private reference; public projections never expose observation IDs/authors/text. Maintenance uses restricted non-HTTP commands and default-deny authority; authorized fixture authority lives only in tests.
